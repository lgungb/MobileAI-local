### 1.3 关键判断：**「讲工具」这条路在抖音不通，替代路径是什么？**

先看一个**同赛道真实样本**（二手转述，需核实）：

> B 站 UP 主「青青王-AI」2025-9-10 发布「吃灰旧安卓手机本地跑大模型、对外提供 OpenAI 兼容接口」：**B 站 26 赞 / 76 收藏；小红书 74 赞 / 197 收藏**。
> 来源：什么值得买《"闲置设备 AI 再就业"这波，实测分层在这》。

请盯住这两个数字的关系：**收藏率 ≫ 点赞率**。

- **它证明了什么**：需求**是真的**——用户「先收藏，周末动手」，说明有明确的行动意图。
- **它暴露了什么**：**公开平台的传播力极弱**。技术演示能让人"想存下来"，但**打不动人"想转出去/想看完"**。因为它**没有情绪、没有 3 秒冲突**。
- **给我们的启示**：客户的内容**不能复制这个形态**。同一件事，换一个「戏剧动作」当入口，数据模型完全不一样。

**所以，有效传播形态的答案是：**

> **不是「讲工具」，是「做实验」。**
> 用**一个 3 秒能拍出来的物理动作**制造悬念，让观众自己得出"这玩意居然不用网"的结论。
> 首选动作：**把手机调到飞行模式（状态栏飞机图标亮起）** ← 这是全网公认的"端侧 AI 测谎仪"。

为什么是它（有据可依）：
- 「飞行模式测试」已是**国际通用的端侧 AI 验证法**，被多家媒体写成方法论：Personal LLM《10 Checks》、CortexOS《The Airplane Test》（称"Airplane mode is the lie detector"）、Tom's Guide、MakeUseOf、meetaitools 均以"断网还能不能跑"为核心测试。
- 它**天生长了一张抖音脸**：可视化（飞机图标）、二元结果（能用/不能用）、可复现（人人能拍）、反直觉（断网还能听书）。
- 它**天然规避绝对化红线**：你展示的是**一个可验证的动作**，不是一句"100% 安全"的承诺。

**替代路径定调**：
```
需求锚点（抖音已有流量池）：听书 / 听小说 / 听文档
     ↓
情绪外壳：没网也想听 / 不想让平台知道我听了什么
     ↓
戏剧动作（3 秒钩子）：开飞行模式
     ↓
技术彩蛋（差异点）：它把整本书读完了，而且原文一个字节都没出手机
     ↓
CTA：本机跑的 / 这是怎么做到的
```

> **与视觉基线对齐**：本条判断与视觉总监 `视觉基线规范 v1.0` 已产出的 **模板 A「对比冲击型」（联网 vs 断网、云端上传 vs 本地处理）完全同频**。选题的「视觉钩子」列已按 A / B / C 三模板标注，可直接开工。

## 2.0 ⚠️ 合规前置警告（主笔/视觉动手前必读）

客户的**第一卖点是"隐私不泄露"**，这恰好是**最容易踩线的一句话**。硬约束：

1. **禁止绝对化表述**：不得出现"100% 安全""绝对不泄露""永久免费""万无一失""唯一""第一"等极限词（《广告法》红线）。
2. **不得暗示"手机上就绝对安全"**。官方口径（首都网警/今日头条《AI 住进手机，我们的隐私就稳了么？》）明确：**"不出门"≠"绝对安全"**——App 权限滥用、设备被控仍有风险。
   → 正确表述：**"数据不上传 / 原文不出手机 / 断网也能用"**（可验证的动作），**而非**"绝对安全 / 没人能拿到"。
3. **健康/医疗类文档一律脱敏**。若做"体检报告不出手机"类选题，画面**必须打码**，且**不做任何医疗解读**，只演示"文字转语音、数据不出机"。
4. **AI 生成内容需标注**。若视频用到 AI 配音/AI 生成画面，按平台要求加标注。
5. **不编造"数据被偷"的恐怖结论**。隐私类内容只讲**可验证的机制**（"云端 AI 要联网才能跑"是常识事实），不虚构"你的数据正被 XX 售卖"。

> **清单结构提示**：18 条中，**引流型 ≈ 10 条 / 信任型 ≈ 3 条 / 纯涨粉型 ≈ 5 条**。建议首个 30 天按 **7 : 2 : 1（引流 : 信任 : 转化）** 配比投放，前 3 条务必用 A 组（断网实测）破局，不要一上来就讲原理。

## 3. 分层结论

### 3.1 Top 3（按潜力评分排序 & 为什么是这三条）

| 排名 | 选题 | 分数 | 为什么是它（而不是别的） |
|---|---|---|---|
| **1** | **#1 我把手机开了飞行模式，它把一整本书读完了** | **9** | 它是**唯一一条把产品最强差异化（长文本不中断）+ 最容易传播的动作（开飞行模式）+ 抖音最大流量池（听书）三合一**的选题。3 秒画面=状态栏飞机图标，人人能拍、人人能懂、反常识。**冷启动第一条就发它。** |
| **2** | **#6 十秒测出一个 AI App 是不是"真本地"** | **9** | 它是**工具型内容**，天生带"收藏 + 转发 + 关注"三重动作（"怕忘了，先存"）。它不推产品，**推一个判断能力**——观众学会后会觉得"这个人有用"，是**最高效的关注理由**。且完美规避绝对化红线。 |
| **3** | **#5 你发给 AI 的每一句话，最后都去了哪？** | **8.5** | 情绪最强、最易出圈。它不解决"听书"，它解决**"为什么要在意"**——是整条内容线的情感发动机。**但它排第三而非第一，唯一原因是合规风险最高**（极易滑向"绝对安全/编造恐吓"），必须严格按 2.0 警告执行。 |

> **为什么不是 #8（会议录音）或 #11（PDF 朗读）**？它们**变现最近、需求最真**，但**情绪入口比 Top 3 弱**。定位为「第二梯队主攻」，第 2 周起接上，用来筛"高付费意愿人群"。

### 3.2 内容公式（可重复引爆的结构）

**主公式 ——「同一个动作，联网 vs 断网」对照实验**

```
0–3s   【悬念】亮出物理动作：手指点开飞行模式，状态栏飞机图标亮起
3–8s   【反直觉】原以为会卡住，结果它照常出结果 / 把书读下去了
8–15s  【揭示差异】"刚才它一个字都没联网"——把技术点当彩蛋，不当开场
15–20s 【落点】CTA：这是本机跑的 / 想知道怎么弄，评论区说一声
```

三个可轮换的变体（避免同质化）：
- **变体 1「时长对比」**：联网等 8 秒 vs 断网秒出
- **变体 2「对象对比」**：云端 AI 转圈 vs 本地 AI 直接读
- **变体 3「场景对比」**：隧道里卡住 vs 隧道里照读

**副公式 ——「把损失演出来」**（用于隐私组）
> 「你以为它在读书，其实它在传数据」→ 用一条"虚线飞出手机"的可视化，把抽象的上传行为变成可见动作。

**节奏铁律**（对齐视觉规范"0.5 秒策略"）：
1. 一条视频**只讲一个冲突**（一个动作 + 一个反常识结果）。
2. **技术名词（NPU / 量化 / 端侧）一律不上口播**，只在字幕/评论区出现——抖音用户词汇表里没有它们。
3. 词汇替换表：`端侧 AI` → "装在手机里的 AI"；`离线推理` → "没网也能用"；`数据不出端` → "原文没出过手机"；`TTS` → "让它念给你听"。

### 3.3 绝对不要碰的 3 条（会限流 / 受众不买 / 无法视觉化）

| 不碰的方向 | 为什么 |
|---|---|
| **① 「零基础教你部署本地大模型」（装模型 / 改参数 / 命令行 / `.gguf` 后缀）** | **三宗罪**：抖音受众不买（极客内容属于 B 站/知乎）；3 秒内无法可视化；步骤太长留不住人。**且会主动吸引错误的粉丝标签**，让账号被算法判成"教程号"，后续卖不了任何东西。 |
| **② 跑分 / 参数对比（tokens/s、7B vs 14B、Q4 vs Q8 量化实测）** | **无情绪曲线**，算法不给推；**测评号粉丝是"遗产"不是"资产"**（观众只为查参数而来，看完即走，不关注、不复购）。对零基础冷启动账号是**负资产**。 |
| **③ 荐机 / 换机种草（"想跑本地 AI 该买哪台手机"）** | **合规风险**（导购/带货需资质与规范）；**与账号垂直度冲突**（账号卖的是"断网也能听书"，不是"买手机"）；**与客户货架无关**（客户手上是一个 App，不是手机渠道）。**绝对不碰。** |

## 4. 竞品爆款拆解（Top 2）

> 说明：**未检索到「端侧 AI」在抖音的直接爆款样本**（这本身就是一个重要信号——该话题在抖音尚未出现爆款形态）。因此选取两个**结构可迁移**的样本：一个证明"该品类的现状天花板"，一个证明"AI 内容在抖音该怎么爆"。均为公开二手信息，**需核实**。

### 样本 A｜B 站 UP 主「青青王-AI」：《吃灰的旧安卓手机本地跑大模型，对外提供 OpenAI 兼容接口》（2025-9-10）

- 来源：什么值得买《"闲置设备 AI 再就业"这波，实测分层在这》转述，**需核实**
- 数据：B 站 26 赞 / 76 收藏；小红书 74 赞 / 197 收藏
- **标题公式**：`吃灰的[闲置设备] + [本地跑上大模型] + [对外提供 XX 接口]`
- **前 3 秒钩子**：类型 = **反常识 / 占便宜**（旧手机特写 + "别扔"）
- **结构骨架**：钩子（旧手机别浪费）→ 正文（演示 + 步骤，**总分结构**）→ CTA（收藏蹲后续）
- **情绪曲线**：好奇 → 门槛焦虑（"tps 不得低完了吗"）→ 动手欲（收藏）
- **互动设计**：评论区天然站队——"最大只能跑 3B，没意思" vs "慢慢跑就完了"（**争议即互动**）
- **转化点**：类型 = **收藏/蹲**（无硬广），**无合规标注**
- **可复用点**：①「旧设备 + 本地 AI」的反差选题；② 用**争议**撬动评论区；③ 断网演示动作
- **不可复制点**：具体技术文案、接口代码、UP 主的技术身份
- **最关键的一条教训**：**收藏率 ≫ 点赞率 = 需求真实但传播弱**。同一件事若搬进抖音，必须**换情绪钩子**（把"技术接口"换成"没网也能听书"），否则抖音数据会比 B 站更差。

### 样本 B｜抖音博主「南溪以南」：《AI 说唱 + 动物科普》系列（2025 下半年）

- 来源：今日头条 / AIBase 转述，**需核实**。称：3 个月涨粉近百万、总粉丝破 120 万、合集 3.1 亿播放、单条《传奇雌虎"箭头"》236 万赞
- **标题公式**：`用[新形式]打开[旧知识]`
- **前 3 秒钩子**：类型 = **悬念 / 冲突**（强节奏说唱开头，3 秒内抓住注意力）
- **结构骨架**：3 秒强节奏钩子 → 正文（知识 + 故事，**情感叙事结构**）→ 情感落点（缅怀/共情）
- **情绪曲线**：好奇 → 沉浸 → 共情（波峰）→ 转发/评论欲
- **互动设计**：内容本身"有故事、有情绪"，评论区讨论的是**内容**（"这只老虎好传奇"）而非技术（"AI 怎么做的"）
- **转化点**：类型 = 涨粉 → 后续橱窗带货 / 卖课；**有 AI 生成内容，合规标注状态需核实**
- **可复用点**：① **"技术为内容服务"**——把"AI 怎么做到的"退到幕后，让**内容本身**成为主角；② 3 秒强节奏开头；③ 用情感（而非技术惊艳）驱动转发
- **不可复制点**：说唱形式、动物素材、具体文案
- **迁移意义**：它证明了**抖音观众不为"AI"买单，为"知识/情感"买单**。→ 我们的内容**绝不能卖"端侧 AI"，要卖"断网也能听 / 没人知道我在听"**。

## 5. 不推荐的方向（汇总）

| 方向 | 不推荐原因 |
|---|---|
| 端侧 AI 原理科普（NPU/量化/推理） | 受众窄、无法 3 秒可视化、语言不匹配抖音用户 |
| 部署教程（命令行/`.gguf`/参数调优） | 步骤长、留不住人、污染账号粉丝标签 |
| 跑分与参数对比 | 无情绪、算法不推、粉丝是"遗产" |
| 手机荐机/换机种草 | 合规风险 + 垂直度冲突 + 与货架无关 |
| "绝对安全/100% 不泄露/永久免费" | **广告法极限词红线**，且与官方口径冲突（端侧 AI 亦非绝对安全） |
| 医疗/健康文档的解读 | 无资质，触碰医疗合规红线（只能演示"不出机"，不做解读） |
| 编造"你的数据被 XX 盗卖"类恐吓 | 无事实依据，判低质/造谣限流 |
