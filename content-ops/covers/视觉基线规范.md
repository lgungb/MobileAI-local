# Encourage 抖音账号 · 视觉基线规范 v1.0

> 制定：视觉设计总监 颜入画 ｜ 平台：抖音（主阵地）
> 产品：Encourage 端侧 AI 助手（com.encourage.app）— 完全本地、离线可用、数据不出手机
> 目标人群：注重隐私的 TTS 听书用户（地铁 / 睡前 / 省流量场景）

---

## 一、账号视觉定位（唯一推荐）

**推荐路线：③ 有声书场景温度风 为「外壳」＋ ② 隐私信任感 为「骨架」**
—— 命名：**「暖场景 · 冷科技」反差路线**

一句话：**用有温度的生活场景（地铁/床头/耳机）接住人，用冷色的本地/离线硬事实（留在手机）完成差异化。**

### 为什么是它，不是另外三个

| 路线 | 判断 | 代价 |
|---|---|---|
| ① 技术极客冷静风 | ❌ 只推封面用 | 抖音上"端侧/NPU"受众太窄，纯极客风无人脸、无场景，0.5 秒内唤不起情绪，冷启动必死 |
| ② 隐私安全厚重风 | ⚠️ 只取色彩，不取全貌 | 纯安全风（盾牌+锁+深绿）会被认成"杀毒软件广告/清理大师"，正中"骗子软件"雷区 |
| ③ 有声书场景温度风 | ✅ 作为外壳 | 单独用会淹没核心卖点，被当成又一个"听书号"，和喜马拉雅/懒人听书拉不开 |
| ④ 反差硬核风 | ✅ 作为内核手法 | 需要更强的对比元素，制作成本高；场景图拍不出质感就滑向廉价 |

**最终推荐 = ③ 的暖场景外壳 + ④ 的对比手法 + ② 的冷色信任色。**
代价讲清楚：这条路**制作成本高于纯大字封面**，需要"场景素材 + 冷色科技符号"两层合成；而且对场景图的质感有要求，一旦用低质网图就会显得廉价。**权衡后仍推荐，因为它是唯一能同时承载"情感入口"和"技术差异"的方案。**

### 0.5 秒策略（抖音强刷屏）

用户划过的 0.5 秒里，眼睛只能抓三样东西。所以硬规则：

1. **一条封面只讲一个冲突 / 一个数字 / 一个场景**，绝不堆信息。
2. **主标题字号 ≥ 画面高度的 1/8**（1080×1440 画布上 ≥ 180px）。缩到 200px 宽仍要能读出来，读不出就继续放大。
3. **每张封面必须有一块"亮度锚点"**（暖橙 / 米白大色块）。抖音信息流是深色底，纯深色封面会和背景糊在一起；锚点是"抓眼"的唯一手段。
4. **主标题永远压在纯色块上，不压在场景图上**。场景图负责情绪，色块区负责 0.5 秒里能被读到的字。

## 二、色彩体系（精确十六进制）

| 角色 | 色值 | 绑定概念 | 用途 |
|---|---|---|---|
| 主色 · 墨夜蓝 | `#0F1D2E` | 夜 / 睡前 / 隐私的厚重与安全 | 封面主背景、品牌主色 |
| 辅色 · 深海蓝 | `#1B3350` | 层次 / 冷静 / 科技感 | 卡片、次层色块、渐变深端 |
| 强调色 A · 琥珀橙 | `#FF9F45` | 温度 / 床头灯 / 耳机 / 人的场景 | 场景光影、分隔线、头像符号 |
| 强调色 B · 信号青 | `#37E0B0` | 本地处理 / 离线可用 / 安全状态 | "已连接""留在本机"状态点、波形、进度条 |
| 对比冷色 · 灰雾蓝 | `#5C6E82` | "云端上传"那一侧的冷、无生命感 | 对比模板中"联网侧"底 |
| 文字主色 · 暖白 | `#F7F3EA` | 友好、不刺眼 | 主标题 |
| 文字次级 · 雾蓝灰 | `#9FB0C2` | 弱化信息 | 副标题、角标 |
| 浅底备用 · 暖米白 | `#F3EFE6` | 干净、可信、证据感 | 底部信息条、浅底模板 |

**用色规则**：一个大色块做主色（墨夜蓝），最多再加一个强调色（琥珀橙或信号青二选一，不要同屏大面积同时用）。文字与背景必须深底浅字，禁止中间灰对比。

## 三、字体与字号层级（抖音端可用免费商用字体）

### 字体建议（全部可免费商用）
- **主标题**：思源黑体 Heavy / 阿里巴巴普惠体 Heavy / OPPOSans Bold —— 骨架硬、笔画饱满，缩小可读。
- **数字/英文强调**：HarmonyOS Sans / Inter / Bebas Neue。
- **显眼点缀**：站酷高端黑（免费商用，用于"停"类短句）。
- **禁止**：宋体（太文艺、缩略图糊）、手写体/少女体（不专业，卖课感）。

### 字号层级（基准画布 1080×1440，3:4）

| 层级 | 字号 | 说明 |
|---|---|---|
| 数字强调 | 220–280px | 如"一整本""0 流量" |
| 主标题 | 180–220px | ≥ 画面高 1/8，行距 1.15 |
| 副标题 | 64–76px | 一行，≤12 字 |
| 角标/标签 | 48–56px | 胶囊底 |
| 安全边距 | 四边各 72px | 关键信息不进入危险区 |

**抖音裁切安全区**（来自平台通用规范）：主页按 3:4 裁切，信息流中央裁切。**关键文字与主体放在画面中央 60%–70% 区域**，上下各留 15%、左右各留 10% 作危险区。

### 明确禁止项（会让人认为"骗子软件 / 卖课号"）
- ❌ 大红 + 亮黄 + 粗黑描边的"震惊体"配色
- ❌ 金色渐变 / 金币 / 钞票元素（金融诈骗联想）
- ❌ 荧光紫、霓虹渐变（微商 / 虚拟币）
- ❌ 巨大红色感叹号、爆炸贴图、"!!!" 堆叠
- ❌ 盾牌 + 锁 + 深绿的全屏"安全软件"式构图（杀毒软件联想）
- ❌ 极限词与承诺性文案（点""**绝对**"免费领**"这类）

## 四、三套封面模板规范

> 基准画布：**1080 × 1440 px（3:4）**；同时保留 1080×1920（9:16）安全框，主页显示时按 3:4 裁切。
> 所有模板预留**纯色区域**给后期加字（因为图像生成对中文渲染不可靠）。

### 模板 A · 对比冲击型
> 用于「联网 vs 断网」「云端上传 vs 本地处理」

- **版式**：左右分栏，中缝分隔线。
- **中缝分隔线**：宽 8px，琥珀橙 `#FF9F45`，居中垂直分割。
- **左栏（云端侧）**：占宽 50%，底 `#5C6E82`，降饱和处理；放云服务器图标 + 向外的虚线数据流。
- **右栏（本地侧）**：占宽 50%，底 `#0F1D2E`；手机轮廓 + 信号青 `#37E0B0` 光圈 + 声波。
- **主标题**：压在画面上方**跨中缝居中**，暖白 `#F7F3EA`，**4–6 字**。
  - 示例：`数据不出手机`（6字）｜`断网也能用`（5字）｜`不留一行数据`（6字）
- **底部信息条**：1080×180 暖米白 `#F3EFE6` 横条，放墨蓝副标，**≤12 字**。
  - 示例：`同一句话，两种命运`
- **主体物位置**：手机轮廓跨中缝，左半被"云线"牵引，右半留在本机。
- **留白**：上部标题区留白 ≥ 25%；下部米白条内左右内边距 72px。
- **文字压区**：上 1/3 中部纯色区 + 底部米白条。

### 模板 B · 场景痛点型
> 用于「地铁没信号听不了书」「流量告急」「怕聊天记录被读走」

- **版式**：上文下图。
- **上部色条**：占高 40%（0–576px），实心 `#0F1D2E`，**纯色留白放主标题**，左对齐，左内边距 96px。
- **下部画面**：占高 60%（576–1440px），场景插画/照片（地铁车厢 / 床头 / 戴耳机的人），暖橙 `#FF9F45` 为主光。
- **主标题**：**4–6 字**，暖白，压在上部色条中部。
  - 示例：`没信号 也能听`（6字）｜`一个月不用流量`（7字，可拆两行）
- **副标题**：标签胶囊，压在场景图**左上角**，橙底白字或米白底墨蓝字，**≤10 字**。
  - 示例：`离线也能读给你听`
- **主体物位置**：人物略偏右 1/3（视线朝左，指向文字）。
- **留白**：上部标题区四周留白 ≥ 20%；场景区四边裁切危险区不放关键信息。
- **文字压区**：上 40% 色条区。

### 模板 C · 结果展示型
> 用于「手机读完整本书不卡顿」「这些能力全在手机里」

- **版式**：大字满屏 + 底部证据条。
- **背景**：满屏 `#0F1D2E`。
- **主标题**：大字，暖白，压在画面上方 1/3，**≤6 字**。
  - 示例：`一本书 读到底`（6字）｜`30万字不中断`（数字放大）
- **数字强调**：信号青 `#37E0B0` 或琥珀橙，字号 220–280px。
  - 示例：`30万字`｜`0 流量`｜`4 小时`
- **主体物位置**：居中手机竖屏，屏幕显示朗读界面 + 长波形进度条。
- **底部证据条**：占高 15%，暖米白 `#F3EFE6` 横条，放"能力标签"。
  - 示例：`双引擎朗读 · 全程本地`
- **留白**：上部标题区 ≥ 25%；图标漂浮物小而少，不加噪。
- **文字压区**：上 1/3 纯色区 + 底部米白条。

## 六、头像与主页视觉

### 头像
- **方向**：圆角方形 / 圆形安全裁剪，墨夜蓝 `#0F1D2E` 底，中央一枚**极简「耳机 + 锁」组合符号**，单色琥珀橙 `#FF9F45`，粗线、无字。
- **要求**：缩到 40px 仍能辨识；不加字（头像里加字在抖音一律看不清）。
- **交付**：`content-ops/covers/avatar-01.png`（可作底，实际用请导出 800×800，≤5MB，圆形裁切）。

### 主页背景图
- **规格**：**1125 × 633 px**（抖音主页背景通用推荐尺寸）。
- **注意**：**上下各约 100px 会被裁切**，中央约 400px 高为安全区；**底部会被头像/昵称/数据遮挡**，关键内容放**中上部**。
- **文案视觉呈现**（文案由主笔定，我只给版式）：单行，居中，暖白，字号 ≥ 60px，不超过 14 字，不加花体。
- **底色**：`#0F1D2E`，右侧可放极淡的琥珀橙声波装饰（不抢字）。

### 昵称 + 个性签名
- **昵称**：视觉上"上大下小"——昵称中等字重，签名细体、雾蓝灰 `#9FB0C2`，形成主次。
- **签名**：单行 ≤14 字，不加表情堆叠、不加特殊符号堆砌。
- **一致性**：昵称、签名、头像、封面必须同色系，让人刷到第 3 条能认出"是同一个人"。

## 七、A/B 变体建议（不承诺点击率）

1. **变体 A-2**：把模板 A 的"云端侧"改为纯灰 `#8A8A8A` 黑白，右侧保留彩色 —— 赌的是**色彩剥夺造成的"冷/暖"反差**更能让人停下来。
2. **变体 B-2**：把模板 B 的场景从"地铁"换成"床头 + 台灯"，主标题换成睡前向 —— 赌的是**睡前听书人群的时段情绪**比通勤更愿意点进来。
3. **变体 C-2**：把模板 C 的"30万字"数字改为超大号占屏 1/3 —— 赌的是**纯数字钩子**在信息流里更抓眼。

> 说明：以上为方向性判断。实际效果受选题、账号权重、发布时段共同影响，**不做点击率承诺**。数据回来后由 data-analyst 反馈，再迭代。
