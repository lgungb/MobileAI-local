# 03 · 界面与操作流程

本文描述**现在已有的功能页面与操作方式**（从源码 / 内置文案提炼），不做需求分析、不写未来规划。

> 2026-09 改造要点：原来的**首页 + 侧边抽屉**已移除，改为**微信式底部 5 Tab**。
> 本文按当前形态重写，旧版（抽屉导航）的描述已作废。

## 1. 整体界面结构

- 单 Activity：`MainActivity` → Compose 根 `GalleryApp` → `GalleryNavHost`。
- 底部固定 5 个 Tab：**对话 / 功能 / 实验 / 模型 / 系统**。
- **只有这 5 个顶层页面显示底栏**；进入二级页（会话页、模型列表、模型管理、跑分、通知）时底栏自动隐藏。
- Tab 之间**互不堆栈**：切 Tab 不会层层叠加返回，各 Tab 保留自己的状态（列表滚动位置等）。
- 在顶层 Tab 按系统返回键：对话 Tab 退出 App，其它 Tab 回到对话 Tab。

## 2. Tab 1 · 对话（会话列表）

微信式会话列表，展示 「对话 / 识图 / 语音」三类记录，**按最近使用时间倒序**。

| 操作 | 怎么做 |
| --- | --- |
| 打开一个会话 | 点列表条目 → 进入全屏会话页 |
| **新建一个会话** | 点右下角悬浮 **「+」** → 用当前已下载模型建一条新记录并直接进会话 |
| 删除记录 | 长按 / 左滑条目 → 二次确认。删除会**连带删除这条记录名下的聊天记录** |
| 没有任何记录时 | 显示空态，提供「去模型 Tab」按钮引导下载模型 |

列表项显示：别名（未命名时显示「未命名」）、模型名、类型（对话/识图/语音）、
最近使用时间（今天显示时间、昨天显示「昨天」、更早显示日期）。
模型被删或未下载时会显示「模型缺失 / 模型未下载」状态。

## 3. Tab 2 · 功能（Agent 会话列表）

与「对话」Tab 是**同一个列表组件**，只展示 **Agent** 类型的记录。
右下角「+」新建的是 Agent 会话（走 `llm_agent_chat`，带 Skills / MCP 能力）。

## 4. Tab 3 · 实验（Prompt Lab）

单轮问答 / 提示词尝试。提供四类模板：Free form / Rewrite tone / Summarize / Code。
此页是横向 pager，可在**多个模型之间滑动对比**结果。

## 5. Tab 4 · 模型

| 入口 | 说明 |
| --- | --- |
| Audio Scribe | 语音转写（建一条「语音」记录并直接进会话） |
| Ask Image | 图像问答（建一条「识图」记录并直接进会话） |
| Tiny Garden | 游戏化对话（进模型选择列表） |
| Mobile Actions | 手机操作演示（进模型选择列表） |
| **模型下载与导入** | 进入全局模型管理器：浏览 / 下载 / 导入 / 删除模型、查看详情 |

> 前四项显示的是任务自身名称（英文，如 `Audio Scribe` / `Ask Image` / `Tiny Garden`），
> 副标题才是中文说明。

> 没有任何已下载模型时，点前两项会跳到模型管理页引导下载（不会崩溃、不会白屏）。

## 6. Tab 5 · 系统

| 入口 | 说明 |
| --- | --- |
| 帮助中心 | 使用指南与常见问题、隐私说明 |
| 设置 | 见第 9 节 |
| 通知 | 查看已安排的通知列表，可删除 |
| 任务中心 | 定时提醒 / 每日鼓励（见第 11 节） |
| 文件管理器 | 用 SAF 管理 skill 等本地文件 |

## 7. 全屏会话页

从列表点任意一条记录进入。**底栏隐藏**，顶部是模型栏。

- **顶栏**：当前模型（可切换）、推理来源切换（自动 / 本地 / 云端）、
  以及「**另存为特调**」按钮（把当前提示词 + 参数另存为一条新记录）。
- **输入**：文字、图片、拍照、音频、按住说话。
- **提示词**：可编辑角色设定。改完会**写入当前这条记录**（不会写到全局）。
- **参数**：在顶栏配置弹窗改 TopK / Temperature / Max Tokens 等，同样**写回当前记录**。
- **消息操作**：朗读、复制、单条保存、删除、长按多选批量删、导出 Markdown / 分享。
- **返回**：回到列表，这条记录的时间会刷新并置顶。

> 提示词与参数都是**记录级**的：A 记录和 B 记录可以有完全不同的角色设定与采样参数，
> 即使它们用的是同一个模型。

## 8. 会话记录（特调）怎么管理

一条记录 = **模型 + 角色提示词 + 采样参数 + 对话类型 + 别名**。都持久化在本地，重启保留。

| 场景 | 行为 |
| --- | --- |
| 新建 | 对话/功能 Tab 右下角「+」；或模型 Tab 点「识图 / 语音」 |
| 改提示词或参数 | **原地写入当前记录** |
| 想保留原版、另开一条 | 顶栏「另存为特调」→ 生成「XX 副本」，**不会**把当前会话切到新记录 |
| 删除 | 列表长按 / 左滑 → 二次确认，连带删除名下聊天记录 |

## 9. 设置页包含什么

入口：系统 Tab → 设置。

- **主题**：明/暗主题切换。
- **语音设置**：朗读开关、语速/音调、引擎选择（系统 TTS / Sherpa-ONNX 离线）、试听；
  离线语音包下载与状态。
- **云端模型配置**：配置 OpenAI 兼容服务地址 + API 密钥，多套配置管理，
  默认「本地优先」（不启用云端即纯端侧）；密钥硬件级加密保存。
- **本地 API 服务器**：开启后局域网内其他设备可用 OpenAI 兼容 HTTP 接口调用本机端侧模型；
  可设端口 / Token（Bearer 鉴权）。
- **Feature Flag 区**：功能开关。
- 其他：清除数据、协议（TOS / Gemma 条款）等。

## 10. 语音功能怎么操作

- **朗读文本**：会话页消息上的「朗读」按钮；语音设置页「试听」；定时任务到点提醒。
  长文本会**自动分句逐段朗读**，可以完整读完，不会中途截断。
- **语音输入**：输入框语音按钮（HoldToDictate）→ 边说边出字。
- **切换 TTS 引擎**：设置 → 语音设置 → 引擎选择：系统 TTS 或 Sherpa-ONNX 离线（需先下载语音包）。
- 排查「不出声」：logcat 过滤 `AGSpeechManager`，按 onInit 是否 SUCCESS → speak 是否 dispatch
  → Utterance error 三步定位；错误会通过界面提示展示，不再静默失败。

## 11. 定时任务怎么操作

1. 系统 Tab →「任务中心」→ 右上「+」新增任务。
2. 填：标题、内容（提醒/鼓励文案）、时间（时:分）、按星期重复掩码、可选 AI 提示词。
3. 保存后由 AlarmManager 调度；到点发通知 + 朗读内容。
4. 支持「立即运行」测试、编辑、删除；Android 12+ 未授权精确闹钟时自动降级 setWindow。
5. 重启手机后 `BootReceiver` 自动恢复闹钟。

## 12. Agent / Skill / MCP 怎么操作

- **切换 Agent**：功能 Tab 的会话里，输入框旁「智能体」按钮 → 选择内置
  （鼓励教练 / 翻译 / 编程助手 / 学习导师）或导入自定义 JSON。
- **Skill 管理**：Agent 会话内 Skill 管理面板：查看内置 skills、从 URL / 本地 SAF 导入、删除、测试。
- **MCP 管理**：添加 MCP Server（URL）、查看状态、工具调用前权限确认。
- **云端 API**：设置 → 云端模型配置 → 填入 OpenAI 兼容地址 + 密钥后，
  会话页顶部可切换推理来源（自动 / 本地 / 云端）。

## 13. 模型怎么操作

- **浏览**：模型 Tab →「模型下载与导入」→ 全局模型管理器；分类：LLM / 传统机器学习 / 实验性。
- **下载**：模型详情卡「下载」；WorkManager 后台下载 + 进度通知；支持从 HuggingFace 获取。
- **导入**：本地 `.task` / `.litertlm` 文件导入。
- **试用 / 跑分**：部分模型支持 Benchmark；模型详情里有「运行」和「性能测试」按钮。
- 内置 allowlist 含 Gemma 等 LiteRT-LM 模型（见 `assets/model_allowlist.json`）。

**内存说明**：模型加载后会**保持驻留**，在同一个模型的不同记录之间切换不会重新加载。
只有在**切换模型**、**删除模型**、或**系统内存紧张**时才会释放。

## 14. 界面文案语言

- `res/values/`：默认（英文）与 `res/values-zh/`：简体中文；应用内随系统语言切换。
- 新增文案必须**中英双语同步**（两个文件都加，name 一致）。
