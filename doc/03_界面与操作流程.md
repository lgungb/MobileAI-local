# 03 · 界面与操作流程

本文只描述**现在已有的功能页面与操作方式**（从源码 / 内置文案提炼），不做需求分析、不写未来规划。

## 1. 整体界面结构

- 单 Activity：`MainActivity` → Compose 根 `GalleryApp`。
- 首页 `HomeScreen` 是主界面：顶部 App 标题、分类 Tab（LLM / 传统机器学习 / 实验性）、任务卡片列表、侧边抽屉导航。
- 侧边抽屉（Drawer）分组：
  - **主要**：AI 对话、Agent 对话、提示词实验室
  - **智能**：任务中心、文件管理
  - **系统**：模型、通知、设置、帮助中心

## 2. 首页与主要页面

| 页面 | 入口 | 说明 |
| --- | --- | --- |
| **AI 对话** | 抽屉「AI 对话」 | 与端侧大模型自由对话（LlmChatScreen），支持流式打字机、思考折叠、历史记录、导出 |
| **Agent 对话** | 抽屉「Agent 对话」 | 智能体对话（AgentChatScreen）：可切换预设 Agent、导入自定义 Agent JSON、管理/调用 Skill 与 MCP 工具、配置 Agent 采样参数 |
| **提示词实验室** | 抽屉「提示词实验室」 | 单轮问答/提示词尝试（llmsingleturn） |
| **任务中心** | 抽屉「任务中心」 | 定时提醒 / 每日鼓励：新增、编辑、删除定时任务，设置标题/内容/时间/按星期重复/AI 提示词 |
| **文件管理** | 抽屉「文件管理」 | 用 SAF 管理 skill 等本地文件 |
| **模型** | 抽屉「模型」 | 模型管理页（ModelManager）：浏览/下载/导入/删除模型、模型详情、试用、HF 模型详情 |
| **通知** | 抽屉「通知」 | 查看已安排的通知列表，可删除 |
| **设置** | 抽屉「设置」 | 见下节 |
| **帮助中心** | 抽屉「帮助中心」 | 使用指南与常见问题、隐私说明 |
| **性能测试** | 首页模型卡片 / 模型页 Benchmark 按钮 | 对模型跑分（速度对比、结果查看、基准对比） |

| **手机操作** | 首页任务卡片（MobileActions） | MobileActions 手机操作演示（带挑战对话框） |

## 3. 设置页包含什么（设置 Dialog）

设置入口在首页/抽屉「设置」。现有设置项包括（节选自源码 `SettingsDialog` / 各 Settings UI）：

- **主题**：明/暗主题切换（`ThemeSettings`）。
- **语音设置**（VoiceSettings）：朗读开关、语速/音调、引擎选择（系统 TTS / Sherpa-ONNX 离线）、试听；
  离线语音包下载与状态。
- **云端模型配置**（ApiProviderSettings）：配置 OpenAI 兼容服务地址 + API 密钥，多套配置管理，
  默认「本地优先」（不启用云端即纯端侧）；密钥硬件级加密保存。
- **本地 API 服务器**（LocalServerSection）：开启后局域网内其他设备可用 OpenAI 兼容 HTTP 接口调用本机端侧模型；
  可设端口 / Token（Bearer 鉴权）。
- **Feature Flag 区**：功能开关（见 `FeatureFlags`）。
- 其他：清除数据、协议（TOS / Gemma 条款）等。

## 4. 语音功能怎么操作

- **朗读文本**：对话气泡上的「朗读」按钮；语音设置页「试听」；定时任务到点提醒。
- **语音输入**：输入框语音按钮（HoldToDictate）→ 边说边出字。
- **切换 TTS 引擎**：设置 → 语音设置 → 引擎选择：系统 TTS 或 Sherpa-ONNX 离线（需先下载语音包）。
- 排查「不出声」：logcat 过滤 `AGSpeechManager`，按 onInit 是否 SUCCESS → speak 是否 dispatch → Utterance error 三步定位；
  N6-A 起错误会通过界面提示展示，不再静默失败。

## 5. 定时任务怎么操作

1. 抽屉 →「任务中心」→ 右上「+」新增任务。
2. 填：标题、内容（提醒/鼓励文案）、时间（时:分）、按星期重复掩码、可选 AI 提示词。
3. 保存后由 AlarmManager 调度；到点发通知 + 朗读内容（D2 联动）。
4. 支持「立即运行」测试、编辑、删除；Android 12+ 未授权精确闹钟时自动降级 setWindow。
5. 重启手机后 `BootReceiver` 自动恢复闹钟。

## 6. Agent / Skill / MCP 怎么操作

- **切换 Agent**：Agent 对话输入框旁「智能体」按钮 → 选择内置（鼓励教练 / 翻译 / 编程助手 / 学习导师）或导入自定义 JSON。
- **Skill 管理**：Agent 对话内 Skill 管理 BottomSheet：查看内置 skills、从 URL / 本地 SAF 导入、删除、测试 skill。
- **MCP 管理**：添加 MCP Server（URL）、查看状态、工具调用前权限确认（McpToolCallPermissionDialog）。
- **云端 API**：设置 → 云端模型配置 → 填入 OpenAI 兼容地址 + 密钥后，首页出现云端模型即可直接对话。

## 7. 模型怎么操作

- **浏览**：抽屉「模型」→ ModelManager 列表；分类：LLM / 传统机器学习 / 实验性。
- **下载**：模型详情卡「下载」；WorkManager 后台下载 + 进度通知；支持从 HuggingFace 获取模型。
- **导入**：本地 .task / .litertlm 文件导入。
- **试用 / 跑分**：部分模型支持 Benchmark；模型详情里有「运行」和「性能测试」按钮。
- 当前内置 allowlist 含 Gemma-4-E2B-it 等 LiteRT-LM 模型（见 `assets/model_allowlist.json`）。

## 8. 界面文案语言

- `res/values/`：默认（英文）与 `res/values-zh/`：简体中文；应用内随系统语言切换。
