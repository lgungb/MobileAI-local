# 00 · 索引

本文档是 SeAI_Encourage 工程的中文说明总入口。全部内容**只描述现状与操作**，不含需求分析或未来规划。

## 这是什么

Encourage 是一个端侧优先的 AI 对话 Android 应用：以本地 LiteRT-LM 端侧模型为核心，
可选接入 OpenAI 兼容云端 API，并内置 Agent（智能体）/ Skill（技能）/ MCP / 定时任务 /
语音输入与朗读 / 离线 TTS 等能力。本工程是原 Google AI Edge Gallery 的 Encourage fork，
去 Google 化后保留了「100% 端侧、隐私不出手机」的主线（云端为显式开关的增强项）。

### 当前界面形态（2026-09 改造后）

进入 App 后是**微信式底部 5 Tab**导航（无侧边抽屉、无首页）：

| Tab | 内容 |
| --- | --- |
| **对话** | 会话列表（对话 / 识图 / 语音 三类记录），右下角「+」新建（选提示词 → 选模型） |
| **功能** | Agent 会话列表，右下角「+」新建 |
| **实验** | Prompt Lab（单轮） |
| **模型** | 4 项能力入口 + 模型下载与导入 |
| **系统** | 帮助中心 / 设置 / 通知 / 任务中心 / 文件管理 |

点列表里任意一条记录 → 进入**全屏会话页**（底栏自动隐藏）。
点「对话」Tab 右下角「+」会弹出**两步新建流程**：先选一个常用提示词（角色设定，带标题分组），
再选模型（默认模型置顶，选非默认会提示耗时），三个采样参数用模型默认设置。
详见 `03_界面与操作流程.md`。

### 一条"会话记录"是什么

每条记录 = 一组**特调配置**：模型 + 角色提示词 + 采样参数（TopK / Temperature 等）+ 对话类型 + 别名。
记录持久化在本地（Proto DataStore），重启保留；删除记录会**连带删除它名下的聊天记录**。
这是 2026-09 会话列表改造（T01~T05）的核心，详见 `01_架构说明.md` 第 3.6 节与 `04_功能清单与实现状态.md`。

## 给 AI / 新同事的协作约定

1. 本项目为**可独立构建的最小交接工程**，所有改动应保持 `./gradlew assembleRelease --offline` 可构建通过。
2. 包名 `com.encourage.app` 是应用标识，**不要改**；License 保留 Apache 2.0 原样。
3. 顶层 `skills/`、`mcp/`、`model_allowlists/` 等**不被构建引用**，不要在新工程里按它们改代码；
   实际生效资源在 `app/src/main/assets/`。
4. **文档定位**：本目录只放「现状 + 构建 + 操作 + 已定方案」，不追溯已完成功能的需求分析。
   改动已实现功能时，同步更新对应文档，防止文档过期。设计过程稿不进仓库。
5. **版本号纪律**：每完成一次可构建的提交，`versionCode +1`、`versionName` 末位 +1，
   使 APK 版本号与提交一一对应。稳定基线建议另打 Git tag 锚定。
6. **构建纪律**：构建由人执行（占用内存与 CPU）；构建结束后执行 `.\gradlew.bat --stop` 释放守护进程。
   `gradle.properties` 已限制内存上限，不要上调。
7. **采样参数键名陷阱**：运行时读 `model.configValues` 用的是 `ConfigKey.label`（如 `TopK`），
   而会话记录存的是 `ConfigKey.id`（如 `topk`）。两者**必须显式映射**，直接拷贝会静默失效。
   详见 `01_架构说明.md` 第 3.6 节。

8. **数据层三条硬规则**（违反必出数据 bug，详见 `05_数据与存储.md`）：
   - 写数据**只能在 `updateData { }` 闭包里读改**，禁止"先读快照、后整体覆盖"；
   - **不要新增同步接口**，新代码一律 `suspend`（现有 `runBlocking` 是历史债，正在清）；
   - proto **只加新字段号**，永不改类型、永不复用旧字段号。
