# 00 · 索引

本文档是 SeAI_Encourage 工程的中文说明总入口。全部内容**只描述现状与操作**，不含需求分析或未来规划。

## 这是什么

Encourage 是一个端侧优先的 AI 对话 Android 应用：以本地 LiteRT-LM 端侧模型为核心，
可选接入 OpenAI 兼容云端 API，并内置 Agent（智能体）/ Skill（技能）/ MCP / 定时任务 /
语音输入与朗读 / 离线 TTS 等能力。本工程是原 Google AI Edge Gallery 的 Encourage fork，
去 Google 化后保留了「100% 端侧、隐私不出手机」的主线（云端为显式开关的增强项）。

## 给 AI / 新同事的协作约定

1. 本项目为**可独立构建的最小交接工程**，所有改动应保持 `./gradlew assembleRelease --offline` 可构建通过。
2. 包名 `com.encourage.app` 是应用标识，**不要改**；License 保留 Apache 2.0 原样。
3. 顶层 `skills/`、`mcp/`、`model_allowlists/` 等**不被构建引用**，不要在新工程里按它们改代码；
   实际生效资源在 `app/src/main/assets/`。
4. 需求讨论 / PRD 不进本仓库；`doc/` 只放「现状 + 构建 + 操作」。
