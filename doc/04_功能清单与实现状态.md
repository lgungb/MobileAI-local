## 二、核心能力逐项状态

### 1. 会话记录（特调）【✅ 2026-09 新增，本轮改造核心】

一条记录 = **模型 + 角色提示词 + 采样参数 + 对话类型 + 别名**，持久化在本地，重启保留。

- **代码**：`data/conversation/ConversationProfile.kt`（领域模型 + `ConversationType` 枚举：
  CHAT / IMAGE / AUDIO / AGENT）、`data/conversation/ConversationProfileRepository.kt`
  （CRUD / StateFlow / 级联删除 / 幂等惰性迁移）、
  `ui/conversation/`（列表页、列表项、ViewModel、另存为弹窗）。
- **存储**：`proto/conversation_profile.proto` + `UserData.conversation_profiles`；
  会话侧靠 `ChatSessionProto.profile_id` 归属，关系为 **1 : N**。
- **提示词下沉**：改提示词写入**当前记录**（旧 `system_prompt_$taskId` 降级为"无记录时的默认值"）。
- **参数生效**：记录里的 `configValues` 经 **id → label 映射**写入 `model.configValues` 后生效
  （映射细节见 `01_架构说明.md` 3.6 的"键名陷阱"）。
- **删除**：级联删除名下会话 + `cacheDir` 的 `img_` / `audio_` 缓存。
- **入口**：对话/功能 Tab 右下角「+」新建；模型 Tab 的识图/语音新建；顶栏「另存为特调」生成副本。

### 2. 底部五 Tab 导航 / 统一对话入口【✅】

- **代码**：`ui/navigation/BottomNavBar.kt`（`AppRoutes` / `BottomTab` / `TopLevelTabScaffold`）、
  `ui/navigation/GalleryNavGraph.kt`、`ui/navigation/TaskTabScreen.kt`。
- **现状**：首页与侧边抽屉已移除；5 个顶层 Tab 显示底栏，二级页自动隐藏。
  识图/语音/对话统一路由到 `llm_chat` 会话页；**Agent 记录仍走 `llm_agent_chat`**
  （依赖 Skills / MCP，不能压平为普通对话）。
- **已移除**：输入框上方的「能力选择器」及其整条 `onNavigateToTask` 链路（全仓 0 命中）。

### 3. 端侧本地推理（✅）

  `agent/DefaultAgentRuntimeExecutor.kt`、`data/DownloadRepository.kt`。
- **现状**：本地模型经 LiteRT-LM 引擎跑在 NPU；骁龙 SM8750 打通。

### 4. 模型实例生命周期【✅ 2026-09 调整】

- **策略**：**加载后保活**，只在 ①切换模型 ②系统低内存（`onTrimMemory >= MODERATE` / `onLowMemory`）
  ③删除模型 三种情况释放。

- **例外**：`LlmSingleTurnScreen`（Prompt Lab 多模型横向对比）仍保留退页清理，见 `01` 3.7。

### 13. Mobile Actions / Tiny Garden（🟡，下载源已替换为 ModelScope）

两个模型原本走 HuggingFace（国内不可达 → 点了下不动/下不来）。
现已在 `assets/model_allowlist.json` 里为这两条记录**显式指定 `url`**，改从 ModelScope 下载：

| 模型 | 记录名 | 文件 | 大小 | 下载地址 |
| --- | --- | --- | --- | --- |
| Tiny Garden | `TinyGarden-270M` | `tiny_garden_q8_ekv1024.litertlm` | 288,964,608 B | `https://www.modelscope.cn/models/litert-community/functiongemma-270m-ft-tiny-garden/resolve/master/tiny_garden_q8_ekv1024.litertlm` |
| Mobile Actions | `MobileActions-270M` | `mobile_actions_q8_ekv1024.litertlm` | 284,426,240 B | `https://www.modelscope.cn/models/litert-community/functiongemma-mobile-actions_q8_ekv1024.litertlm/resolve/master/mobile-actions_q8_ekv1024.litertlm` |

**实现机制**：`ModelAllowlist.kt:80` 的 URL 构造是 `url ?: "https://hf-mirror.com/..."`——
清单里写了 `url` 就优先用它，没写才回退 HF 镜像。所以加 `url` 字段即可，**不需要改代码**。
（顺带修正了 MobileActions 的 `sizeInBytes`：原值误填成 Tiny Garden 的 288,964,608，实际 284,426,240。）

**已验证**：两个地址均返回 `206 Partial Content`（支持断点续传），
且首 8 字节是 `LITERTLM` 文件魔数（确认是真实模型文件，不是 Git LFS 指针）。

**待真机验证**：模型能否成功下载、加载并跑通对应任务。
- **Mobile Actions**：`customtasks/mobileactions/` —— 语音控制手机（Intent），完全离线；
  部分操作需辅助功能权限。
- **Tiny Garden**：`customtasks/tinygarden/` —— 种花小游戏。

- **缺口**：两者都缺"就地说明"（这是什么 / 需要什么前置 / 怎么用）。
