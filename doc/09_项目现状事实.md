## 1. 项目是什么（一句话）

安卓端侧优先的 AI 对话应用：本地 LiteRT-LM 模型跑对话，可选接 OpenAI 兼容云端 API，
并在其上做了「会话记录（特调）」+ Agent/Skill/MCP + 语音输入朗读 + 定时任务 + 本地 API Server。

- 包名：`com.encourage.app`
- 语言/框架：Kotlin · Jetpack Compose · Material3 · Hilt
- 单 Activity，界面文件全部是 `.kt`
- 前身是 Google AI Edge Gallery fork，已去 Google 化（无 Firebase、无统计上报）

## 3. 运行时结构（谁启动谁）

```
MainActivity
└─ GalleryApp                    ← 底栏 + NavHost 容器（ui/navigation/GalleryApp.kt）
   └─ GalleryNavHost             ← 路由表（ui/navigation/GalleryNavGraph.kt）
      ├─ tab_chat    ConversationListScreen     会话列表（对话）
      ├─ tab_agent   ConversationListScreen     同一个文件，靠 types 过滤（功能）
      ├─ tab_lab     TaskTabScreen → llmsingleturn/*
      ├─ tab_models  ModelHubScreen
      ├─ tab_system  SystemScreen
      └─ route_model/{taskId}/{modelName}  → LlmChatTaskModule → LlmChatScreen → ChatView
```

启动时（`GalleryApplication.onCreate`）依次做 5 件事：

1. 装全局未捕获异常处理器（崩溃 → `CrashDisplayActivity`）；
2. 设置 `ADSP_LIBRARY_PATH`（NPU 需要）；
3. `NotificationScheduleManager.initialize()`；
4. `LocalServerService.initialize()`（订阅配置自动启停本地 HTTP 服务）；
5. 后台跑 `SessionMigrator.cutoverIfNeeded()`（会话文件化一次性切换）。

**能力是 Task 驱动的**：一个能力 = 一个 `CustomTask`，界面由 `CustomTask.MainScreen()` 提供，
经 Hilt `@IntoSet` 注册后在 `ModelManagerViewModel` 装配。任务 ID 常量见 `data/Tasks.kt` 的 `BuiltInTaskId`。

> 全部走 `data/DataStoreCorruptionHandlers.kt`：坏文件先备份成 `xxx.pb.corrupt-<时间戳>` 再回落默认值。

### 5.2 会话文件（主路径）

```
files/
├── datastore/                ← 5 个 DataStore 落盘处
├── sessions/
│   ├── index.tsv             ← 轻量索引（列表只读这个，不解析正文）
│   └── s_<安全名>-<hash>.pb  ← 单条会话正文（ChatSessionProto）
├── migration_backup/         ← 迁移前 user_data.pb 备份（留最近 2 份）
└── scheduled_notifications.pb
```

- 写：`ChatViewModel.saveSession` → `SessionFileStore.writeSession`（`.tmp` + rename 原子替换）
- 读列表：`SessionFileStore.indexState`（内存镜像）→ `toLiteProto()`
- 读详情：`readSessionContent(sessionId)` 只读那一个文件，失败回退旧字段
- 删记录：级联删名下全部会话文件 + 索引 + `cacheDir` 的 `img_`/`audio_`

### 5.3 其他会落盘的东西

| 位置 | 内容 |
|---|---|
| `cacheDir/img_*`、`audio_*` | 会话图片/音频副本 |
| `externalFilesDir/imports/` | 用户导入的 `.litertlm` |
| `externalFilesDir/<模型>/<版本>/` | 下载的模型 |
| 用户选的 SAF 路径 | 导出的 Markdown |

## 6. 三条必须记住的语义（搞错就是 bug）

| # | 语义 | 唯一真相源 |
|---|---|---|
| 1 | **运行后端（CPU/GPU/NPU）是设备级**，不是会话级 | `Settings.model_accelerators`（modelName → 后端） |
| 2 | **采样参数是记录级**，且键有两套：运行时读 `ConfigKey.label`，记录存 `ConfigKey.id` | `LlmChatViewModel.PROFILE_CONFIG_KEYS` 做映射 |
| 3 | **提示词有三层**，本地引擎只认「初始化时注入的那一个」 | 任务级 `secrets["system_prompt_$taskId"]` / 记录级 `ConversationProfile.systemPrompt` / 云端 `ApiProviderConfig.systemPrompt` |

`ACCELERATOR` / `VISION_ACCELERATOR` **绝不能**进 `PROFILE_CONFIG_KEYS`。
