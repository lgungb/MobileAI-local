# Encourage（端侧 AI 助手）— 发布页

## 这是什么

本仓库是 **Encourage** 端侧 AI 助手的 **APK 发布页**，仅用于发布构建好的安装包供下载，**不含源码**。

Encourage 是一个**完全本地运行**的 Android AI 助手：对话、识图、语音、朗读都发生在设备上，默认 100% 本地推理、数据不出手机；支持端侧 NPU 加速、Agent/Skill/MCP 扩展、本地 OpenAI 兼容接口等能力。

## 下载安装包

前往右侧 **Releases** 页签，选择最新版本下载 `app-release.apk`。

| 项目 | 说明 |
| --- | --- |
| 包名 | `com.encourage.app` |
| 最低系统 | Android 12（API 31），targetSdk 36 |
| 架构 | arm64-v8a |
| 许可 | Apache License 2.0 |

> 安装前请开启「允许安装未知来源应用」。
