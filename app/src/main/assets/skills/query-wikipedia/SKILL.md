# 百度百科查询

## 使用说明

调用 `run_js` 工具，使用 `index.html`，并传入 JSON 格式的 `data`，包含以下字段：
- **topic**：必填。仅提取主要实体、人物或事件（例如"2026奥斯卡"、"爱因斯坦"）。必须移除所有具体问题细节、动作词或对话文本（例如不要包含"获奖者"、"最佳影片"、"谁赢了"、"历史"等词）。搜索宽泛主题，以便工具返回主要词条。

**约束：**
- 提供简洁摘要（1-3个完整句子）以节省上下文。确保回复以完整句子结尾。回复必须使用与用户原始提问相同的语言。
- 对于周期性事件或时效性事实，查询具体届次（例如"2026奥斯卡"）。如果用户省略年份，默认为当前年份。
- 如果在摘要中找不到用户问题的确切答案，简要说明，然后主动提供在文本中找到的相关信息。
